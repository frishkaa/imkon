# Видео «Новая модель нотариата»

Ролик ~100 сек, 1920×1080, 30 fps, на русском: реальные стоковые видео + анимированная
графика поверх (титры, чек-лист нотариуса, интерфейс платформы «Нотариат», схема
движения денег, эффект для бюджета, карта пилота). Сделан на [Remotion](https://www.remotion.dev).

## Сюжет (10 сцен)
| # | Сцена | Кадры |
|---|-------|-------|
| — | Заставка | горы, заголовок |
| 01 | Покупка квартиры | стройка (таймлапс, краны), покупатели в касках, застройщик, рукопожатие |
| 02 | Как сейчас | бумаги; 3 проблемы действующей модели |
| 03 | У нотариуса | встреча у нотариуса; проверка личности, права собственности, дееспособности |
| 04 | Платформа «Нотариат» | ноутбук → интерфейс: расчёт налога от большей суммы, реестр должников, платежи |
| 05 | Движение денег | оплата → схема «1 оплата → платформа → 5 получателей» |
| 06 | Документы на руках | печать, подпись, передача документов и ключей |
| 07 | Эффект для бюджета | 4 источника выгоды, итог, пример Франции |
| 08 | Пилот | карта Таджикистана: Душанбе, Худжанд, Бохтар, Куляб |
| — | Финал | цитата «Платформа без нотариуса…», логотип |

## Где менять тексты и цифры
**Все тексты и цифры — в [`src/data.ts`](src/data.ts).** Цифры там предварительные
(черновик): поправьте и перерендерьте.

## Запуск
```bash
npm install
./scripts/fetch-footage.sh        # скачать и нарезать видеоклипы (≈90 МБ)
python3 music/compose.py 100      # (необязательно) пересобрать музыку — нужен fluidsynth + fluid-soundfont-gm
npm run studio                    # предпросмотр в браузере
npm run render                    # → out/notariat.mp4
```
В облачном контейнере перед рендером:
`export REMOTION_CHROME=/opt/pw-browsers/chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell`
